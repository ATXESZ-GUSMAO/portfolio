# Portfólio · Lucas Gusmão

Site pessoal com meus projetos, stack e experiência como desenvolvedor full-stack (foco em backend).

## Stack

- React 18 + TypeScript
- Vite
- CSS puro com tema claro e escuro automático
- Deploy na Vercel

## Rodando localmente

```bash
npm install
npm run dev
```

## Editando o conteúdo

Todo o texto do site (projetos, stack, experiência e contatos) fica em `src/data/content.ts`. Para adicionar um projeto, inclua um item no array `projects`.
